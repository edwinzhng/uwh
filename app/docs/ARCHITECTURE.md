- Stack: Expo Router, React Native, Convex, Jotai, TypeScript and Bun.
- `app/`: thin route entries and navigation layouts.
- `src/features/`: product screens and workflows composed from the public design-system API.
- `src/design-system/`: shared visual components and platform adapters; foundations come from `packages/design-system`.
- `src/backend/`: reactive query, authentication and command controllers. Screen-owned providers keep retained route data separate from the globally active workspace.
- `src/domain/`: platform-independent policy, validation and transformations.
- `src/demo/`: isolated fictional preview state; never a fallback for live failures.
- `convex/`: authorization, persistence and scheduled work. The legacy backend remains separate.
- `scripts/` and `tests/`: build checks, guarded verification and behavioral regression coverage.
- Follow the [engineering guide](engineering/README.md), [form rules](FORMS.md), [design-system owners](DESIGN-SYSTEM.md) and [migration setup](LOCAL-REAL-DATA.md). Keep environment and release details in their existing operational documents.
