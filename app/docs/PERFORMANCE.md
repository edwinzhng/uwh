- Scope reactive queries to the screen and authorized audience; paginate growing histories and bound mounted rows.
- Retained native screens own their data snapshots. Navigating elsewhere must not replace a retained screen’s data with another route’s working set.
- Register initial layout dependencies with page readiness. Keep pagination and later updates local instead of blanking a ready page.
- Cancel abandoned timers, requests and animation work. Pause inactive decoration without resetting its visible frame.
- Use native stack transitions and UI-runtime animation on native; prefer compositor transforms and opacity on web.
- Run `bun run check` in `app`. Run `bun run check:motion` in both `app` and `site` after motion changes.
- Use `EXPO_PUBLIC_CONVEX_URL=http://127.0.0.1:3210 bun run verify:performance` for the guarded local scale fixture; it cleans up its own records. Do not point fixture checks at production.
- Browser checks and bundle exports do not establish native performance. Profile a release build on supported hardware for keyboard/gesture interruption, background/resume, slow networking, long scrolling and memory growth.
