- An administrator can open an archived member’s Admin panel, choose “Merge into active member,” and review a specific active profile. The preview lists affected records, optional empty-profile fields, and actionable conflicts. The final action requires the active member’s full name and an unchanged preview fingerprint. Overlapping calls and exact retries create one audit and one canonical result.

- The active member keeps their name, current goal and structured goal revisions, registration projection, rating, positions, and private coaching settings. Program memberships combine without changing login IDs, administrator access, or coaching permissions. Affected program revisions advance so a previously opened roster editor cannot undo the identity change. Existing target contact and photo values win; filling empty fields requires an explicit checkbox.

- The archived source member is not deleted. It becomes a read-only alias through `mergedInto` and `mergedAt`; old member links open the canonical profile. The audit preserves both original member snapshots, affected-record counts, selected profile fills, and prior derived dues, tracker, season, and coaching summaries. Original profile and coaching metadata remain on the alias. Shared profile photos are retained while either saved profile references them.

- Self and guardian membership links move without granting roles. Distinct self-login users or different non-empty private audiences block the operation. Active pending login invitations must be revoked before merging an identity with an existing audience. Calendar subscription and direct-conversation natural-key collisions also require review.
- Attendance responses retain database IDs; their explicit event/person keys change. Feedback, shoutouts, loans, payments, attendance flags, coaching hours, and import references relink through typed fields. User IDs, message authors, conversation access lists, ledger snapshots, and external import fingerprints do not change.
- Current dues reconcile only when at most one profile has non-zero dues. Identical tracker summaries can collapse; differing values block. Two populated season summaries block until reconciled; original financial ledger entries retain IDs and content. Redundant derived summaries are preserved in the merge audit before removal.
- Goal reflections retain their original goal snapshot, self-rating, author, note, and date. Coach reviews retain all rows and observations. Source rounds precede target rounds under new unique round numbers with original person/round coordinates retained. A source open round becomes preserved history; a new current round must be started explicitly. An existing target current round remains current, with a bumped revision.
- All lineup person fields are explicit, including field slots, referees, benches, assignments, attendees, and exclusions. Co-occurrence blocks merging. Every affected lineup advances revision; completed publication history stays intact, while future or unavailable-event lineups become unpublished and stale. Committed enrollments retain disjoint and empty historical intervals; overlapping intervals block.
- Private energy check-ins and fitness results retain record IDs, actors, values, and notes. Same-session collisions block atomically. Fitness aggregates rebuild from preserved results, and affected result-session revisions advance.
- Tagged resources retain media/file IDs. Relinking a private audience requires the target to have already been explicitly tagged. Session plans have no person references. Inbox entries resolve their source entities and recheck current visibility instead of copying household access.

- Every module preflights before any write. Bounded scans and transaction-size checks stop oversized histories for a reviewed migration, without partially updating data. The fingerprint includes the relevant records and roster state, not a generic JSON replacement. Account erasure expands canonical identities to their aliases and removes matching private merge audits and profile/history records.
